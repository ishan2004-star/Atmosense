# Atmosense 🌤️

Atmosense is a feature-rich, beautiful, and highly responsive weather application. Designed with modern UI/UX principles, it delivers real-time weather data and environmental insights at your fingertips. 

Whether you're checking the temperature in your local city via GPS or exploring the climate of a country across the globe, Atmosense provides comprehensive and accurate weather metrics.

## ✨ Features

- **Real-Time Weather Data:** Get current temperature, "feels like" temperature, and descriptive weather conditions.
- **Advanced Metrics:** Dive deeper with details like Wind Speed, Atmospheric Pressure, Visibility, and Min/Max Temperatures.
- **Environmental Insights:** Check the **UV Index** and **Air Quality Index (AQI)**, complete with severity levels (e.g., Good, Moderate, Hazardous).
- **Smart Search:** Search by City, Country, or both. Seamlessly supports "Enter" key submissions for quick lookups.
- **Geolocation Support:** Instantly fetch weather data for your current location using the built-in GPS button.
- **Dynamic Visuals:** The application features dynamic background images and changing weather icons that reflect the current climate conditions.
- **Responsive Design:** A beautifully aligned and visually consistent user interface that works perfectly across different screen sizes.

## 🚀 Technologies Used

- **HTML5:** For structuring the application.
- **CSS3:** For a premium, responsive, and visually appealing layout.
- **Vanilla JavaScript:** For robust logic, DOM manipulation, and API integrations.
- **APIs Integrated:**
  - [OpenWeatherMap API](https://openweathermap.org/) (Weather, UV Index, and AQI data)
  - [REST Countries API](https://restcountries.com/) (Country code resolution and full-text search)

## 🛠️ Setup & Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/your-username/atmosense.git
   ```
2. Navigate to the project directory:
   ```bash
   cd atmosense
   ```
3. Open `index.html` in your web browser, or use a local development server like Live Server in VS Code.

*Note: The app uses a built-in OpenWeatherMap API key for demonstration. If you plan to fork and deploy, consider replacing it with your own API key in `script.js`.*
